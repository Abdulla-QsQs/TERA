# Support

## Using TERA

Read the [README](README.md), [Privacy Notice](PRIVACY.md), and
[Content Policy](CONTENT_POLICY.md) first. For a reproducible software defect,
open a GitHub issue using the bug-report template. Do not attach exam PDFs,
student data, credentials, or private documents.

## Privacy, security, and rights requests

- Privacy or deletion request: `abdullahazam1077@gmail.com`
- Security vulnerability: use GitHub private vulnerability reporting; if that
  flow is unavailable, email `abdullahazam1077@gmail.com` with the subject
  `TERA security report`.
- Copyright, source-removal, or takedown request: email
  `abdullahazam1077@gmail.com` with the subject `TERA rights request` and
  identify the affected integration or URL.

The pilot aims to acknowledge safety, privacy, and rights requests within five
working days. General feature requests do not have a guaranteed response time.
