# School pilot plan

## Entry gate

Complete every P0 item in `RELEASE_CHECKLIST.md`, obtain content-source clearance appropriate to the pilot, and use only lawfully acquired local inputs where clearance is uncertain.

## Scope

Start with 3–5 institutions, 10–20 staff users, and no student accounts. Nominate one staff reviewer per institution. Run for four weeks before wider promotion.

## Acceptance criteria

- 100% of a stratified 100-paper validation set has no missing, duplicated, reordered, clipped, or illegible content pages.
- Every generated file is visually checked before bulk printing during the pilot.
- At least 95% of attempted supported papers compile without intervention.
- All high-severity security, privacy, accessibility, and content-rights findings are closed.
- Institutions confirm actual print counts separately from local estimates.
- Support and takedown requests receive acknowledgement within five working days.

## Test matrix

Cover current Chrome, Edge, Firefox, and Safari; Windows, macOS, iOS/iPadOS, Android; portrait and duplex printing; common laser-printer drivers; keyboard-only operation; 200% zoom; and a screen-reader pass.

## Evidence to retain

Keep only non-identifying aggregates: supported paper reference, input/output page counts, compile result, browser family, and reviewer pass/fail. Do not retain PDFs, filenames containing personal data, student data, full IP addresses, or source URLs in analytics.
