# Paper-impact measurement

TERA reports a conservative printable-page comparison for every successful compilation:

`pages avoided = max(0, source QP pages + source MS pages - generated booklet pages)`

`reduction percentage = pages avoided / source pages × 100`

The individual booklet total includes its TERA cover. The Mega total uses the final merged page count, so it reflects removed individual covers and any added combined threshold pages. The figure measures printable PDF pages, not sheets: duplex printing changes sheets but not page impressions.

Do not turn the result into a worldwide environmental claim without observed usage. A defensible pilot report should record only aggregated, consented totals and clearly separate:

- compilations from actual print jobs;
- pages from physical sheets;
- estimated avoidance from independently confirmed avoidance;
- recycled from virgin paper;
- default printer settings and failed/reprinted jobs.

For the first evidence report, sample at least 100 papers across subjects, years, sessions, variants, and mark-scheme lengths, then obtain print-room confirmation from participating institutions. Publish the sample, formula, uncertainty, and failure count alongside any headline number.
